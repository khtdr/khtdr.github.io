# Sharing lists

Open a list, click **Share**, and add people by email. Each person is an
**Editor** (can change tasks) or a **Viewer** (can read and comment).

A public link makes a list readable by anyone who has the link, without an
account. Public links are read-only and can be turned off at any time from the
same menu, which breaks the old link.

Workspace owners can turn public links off for the whole workspace in
**Settings → Workspace**.
